# SmartDoc Manager - Cloud Document Management System

A full-stack cloud-based document management system built with Flask and Google Cloud Platform.

## 🚀 Features
- **File Upload/Download** to Google Cloud Storage
- **User Authentication** system
- **Responsive Web Interface** with Bootstrap
- **AI-Powered Document Analysis** (Google Vision API)
- **Auto-scaling** on Google App Engine

## 🏗️ Architecture
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Backend**: Python, Flask
- **Cloud**: Google App Engine, Cloud Storage, Vision API
- **Database**: Cloud Storage (file metadata)
